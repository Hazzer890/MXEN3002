Milestone 1.2  Station purpose

The Distributing station is the first station in the line. Its job is to separate single workpieces from a stack magazine and feed them, one at a time, to the next station. A double-acting ejecting cylinder pushes the lowest workpiece out of the gravity magazine into a pick-up position; a swivel arm with a vacuum suction cup then grips the workpiece, swivels it from the magazine to the downstream hand-over position, and releases it with an ejector (blow-off) pulse. Limit switches confirm each end position, a vacuum sensor confirms the grip, and a magazine-empty sensor stops the station when the stack is exhausted. Hand-over to the next station is coordinated by the IP_FI ("succeeding station free") signal.

Milestone 1.4  Control panel : FB_Panel

The panel is a three-state machine shared by all three stations. Buttons request transitions; lights report the state. Invalid transitions have no edge and are therefore ignored.

Implemented in ladder as three latched state bits (set/reset by the transitions); the equivalent Structured Text is the canonical source:

FUNCTION_BLOCK FB_Panel
VAR_INPUT
    s1_start : BOOL; s2_stop : BOOL; s4_reset : BOOL;
    error_in : BOOL;      // latched fault from an actuator FB or the Env block
    reset_done : BOOL;    // TRUE when every actuator reports at_home
END_VAR
VAR_OUTPUT
    run_mode : BOOL; reset_mode : BOOL; pause_mode : BOOL; error_mode : BOOL;
    start_light : BOOL; reset_light : BOOL;
END_VAR
VAR state : INT := 0; END_VAR   // 0 PAUSE 1 RUN 2 RESET 3 ERROR

IF error_in AND state &lt;&gt; 3 THEN state := 3;      // forced from any state (1.6 on)
ELSIF state = 0 THEN
    IF s1_start THEN state := 1; ELSIF s4_reset THEN state := 2; END_IF;
ELSIF state = 1 THEN
    IF s2_stop THEN state := 0; END_IF;             // S4 ignored in RUN
ELSIF state = 2 THEN
    IF s2_stop OR reset_done THEN state := 0; END_IF;   // S1 ignored in RESET
ELSIF state = 3 THEN
    IF s4_reset THEN state := 2; END_IF;            // S1/S2 ignored in ERROR
END_IF;

run_mode := (state=1); pause_mode := (state=0);
reset_mode := (state=2); error_mode := (state=3);
start_light := run_mode; reset_light := reset_mode;
END_FUNCTION_BLOCK

For the panel-only milestone 1.4 the two robustness inputs are tied off (error_in := FALSE, reset_done := FALSE), leaving exactly the three states of Figure 2: RESET then exits only on Stop, which the invalid-transition steps require. The ERROR state and the reset_done fall-back are the milestone 1.6 update, drawn in Figure 12; once actuators exist, reset_done returns the panel to Pause when homing finishes, so error recovery is the two presses (Reset, then Start) that the test protocol asks for.

Result, 1.4. Power-on: all lights off (Pause). Start→Start light on (Run). Stop→off (Pause). Reset→Reset light on. Stop→off (Pause). Start pressed in Reset and Reset pressed in Run: no change, never two lights on. All six protocol steps observed.  PASS, 2/2. Tutor:     Date:  

Milestone 1.5  Swivel arm : FB_Actuator_T1 (proper)

The swivel arm is a holdable double-solenoid actuator: pause stops it mid-stroke and resume continues to the same target; reset drives it home.

Sensors and solenoid valves used by this actuator

SignalAddrTypeFunctionFB terminal
Station_3S10.04Input, limit switchArm in magazine (arm_in_magazine) — the arm's home position, the position the reset sequence drives it tosensor_home
Station_3S20.05Input, limit switchArm in downstream hand-over position (arm_in_downstream) — the arm's end positionsensor_end
Station_3Y11.03Output, solenoid valveSwivel arm towards the magazine (arm_2_magazine)valve_to_home
Station_3Y21.04Output, solenoid valveSwivel arm towards the subsequent station (arm_2_downstream)valve_to_end

Home is the magazine position, as required by test 1 of protocol 1.5 ("the arm must move to its home position, the magazine position"). The two valves are a double-solenoid pair: exactly one is energised while the arm travels, and both are off when it is paused mid-swivel, which is what holds the arm in place.

The two pause_action_* states are what makes the arm holdable: entering one drops both valves, so the arm freezes where it is, and run_mode returns to the same travelling state, continuing towards the same target rather than jerking home. Every reset edge leads to action_2_home, which aborts whatever stroke was in progress and drives the arm to the magazine. T1_leaving_home / T1_leaving_end are the move requests issued by the Env block (Figure 11); in code they arrive on the block's single go input, which requests the next stroke from whichever end the arm is sitting at.

One block covers both variants; the robust input arms the stall timer used by milestone 1.6 and is FALSE here.

FUNCTION_BLOCK FB_Actuator_T1   // holdable double-solenoid; arm and (reused) lift
VAR_INPUT
    run_mode : BOOL; pause_mode : BOOL; reset_mode : BOOL; error_mode : BOOL;
    sensor_home : BOOL; sensor_end : BOOL; go : BOOL;
    t_stall : TIME := T#2s; robust : BOOL := FALSE;
END_VAR
VAR_OUTPUT
    at_home : BOOL; to_end : BOOL; at_end : BOOL; to_home : BOOL;
    valve_to_end : BOOL; valve_to_home : BOOL; error : BOOL;
END_VAR
VAR state : INT := 0; stall : TON; moving : BOOL; END_VAR

CASE state OF
0:  IF error_mode THEN state := 4;
    ELSIF reset_mode THEN IF NOT sensor_home THEN state := 3; END_IF;
    ELSIF run_mode AND go THEN state := 1; END_IF;
1:  IF error_mode THEN state := 4;
    ELSIF reset_mode THEN state := 3;
    ELSIF pause_mode THEN ;
    ELSIF sensor_end THEN state := 2; END_IF;
2:  IF error_mode THEN state := 4;
    ELSIF reset_mode THEN state := 3;
    ELSIF run_mode AND go THEN state := 3; END_IF;
3:  IF error_mode THEN state := 4;
    ELSIF pause_mode AND NOT reset_mode THEN ;
    ELSIF sensor_home THEN state := 0; END_IF;
4:  IF reset_mode THEN IF sensor_home THEN state := 0; ELSE state := 3; END_IF; END_IF;
END_CASE;

valve_to_end  := (state = 1) AND NOT pause_mode;
valve_to_home := (state = 3) AND NOT pause_mode;
moving := valve_to_end OR valve_to_home;
stall(IN := robust AND moving, PT := t_stall);
IF stall.Q THEN state := 4; END_IF;
IF state = 4 THEN valve_to_end := FALSE; valve_to_home := FALSE; END_IF;

at_home := (state=0); to_end := (state=1); at_end := (state=2);
to_home := (state=3); error := (state=4);
END_FUNCTION_BLOCK
Result, 1.5 (proper). Reset with the arm in-between drove it home. In Run the arm cycled magazine↔downstream continuously. Stop mid-swivel froze it; Start resumed forward to the end without jerking home (both directions). Reset from a paused stroke returned it home.  PASS, 2/2. Tutor:     Date:  

Milestone 1.6  Swivel arm : FB_Actuator_T1 (robust)

The robust variant is the same block with robust := TRUE: a stall timer runs whenever a valve is driven, and forces the error state if the arm is held. The sensors and valves are unchanged from milestone 1.5; what is added is an error_state output back to FB_Panel, which raises Q2 and returns error_mode to every block.

Figure 6 is Figure 4 with the two stall timers and Error_state added; the proper-mode transitions, including the four reset_mode edges into action_2_home, carry over unchanged and are left off here to keep the new edges legible. A timer accumulates only while its valve is energised, so a paused arm never trips one, and not_being_reset keeps the reset stroke (which may legitimately be slow from an arbitrary position) out of the error path. The only way out of Error_state is reset_mode, which homes the arm.

Tuning (bench). Measured swivel travel ~0.8 s each way, so t_stall was left at T#2s. Healthy strokes never tripped it, and a manual hold reached Q2 at ~2 s as intended.
Result, 1.6 (robust). Holding the arm mid-swivel >2 s raised Q2 and stopped motion (home→end and end→home). Start in the error state did nothing; Reset then Start returned the arm to continuous motion. Q2 also lights when the arm is manually held.  PASS, 2/2. Tutor:     Date:  

Milestone 1.7  Ejection cylinder : FB_Actuator_T2 (proper)

The ejection cylinder is stroke-completing: pause takes effect only at the end of a stroke, so a Stop mid-travel completes to a limit switch and halts there.

Sensors and solenoid valves used by this actuator

SignalAddrTypeFunctionFB terminal
Station_1B10.02Input, limit switchEjection cylinder retracted — the cylinder's home position, the position the reset sequence drives it tosensor_home
Station_1B20.01Input, limit switchEjection cylinder extended, workpiece pushed clear of the magazine — the end positionsensor_end
Station_1Y11.00Output, solenoid valveMagazine eject: energised = extend, de-energised = spring returnvalve_extend

A single solenoid, so there is no valve that commands the retract stroke; the valve is held on at at_end so the cylinder can halt extended during a pause, and dropping it is what starts the return. That is also why this actuator cannot stop in-between: with one valve there is no way to trap it mid-stroke.

There are no pause states on the travelling transitions, which is exactly the stroke-completing requirement: pause_mode appears only as a self-loop on at_home and at_end, so a Stop pressed mid-travel is not acted on until the cylinder has reached a limit switch. From power-up the cylinder's position is unknown, so idle holds until the operator's first reset drives it home through action_reset_2_home.

FUNCTION_BLOCK FB_Actuator_T2   // stroke-completing, two sensors; ejector and (reused) branches
VAR_INPUT
    run_mode : BOOL; pause_mode : BOOL; reset_mode : BOOL; error_mode : BOOL;
    sensor_home : BOOL; sensor_end : BOOL; go : BOOL;
    t_stall : TIME := T#2s; robust : BOOL := FALSE;
END_VAR
VAR_OUTPUT
    at_home : BOOL; to_end : BOOL; at_end : BOOL; to_home : BOOL;
    valve_extend : BOOL; error : BOOL;
END_VAR
VAR state : INT := 0; stall : TON; moving : BOOL; END_VAR

CASE state OF
0:  IF error_mode THEN state := 4;
    ELSIF reset_mode THEN IF NOT sensor_home THEN state := 3; END_IF;
    ELSIF run_mode AND go THEN state := 1; END_IF;
1:  IF error_mode THEN state := 4; ELSIF sensor_end THEN state := 2; END_IF;
2:  IF error_mode THEN state := 4;
    ELSIF reset_mode THEN state := 3;
    ELSIF run_mode THEN state := 3; END_IF;
3:  IF error_mode THEN state := 4; ELSIF sensor_home THEN state := 0; END_IF;
4:  IF reset_mode THEN IF sensor_home THEN state := 0; ELSE state := 3; END_IF; END_IF;
END_CASE;

valve_extend := (state = 1) OR (state = 2);
IF state = 4 THEN valve_extend := FALSE; END_IF;
moving := (state = 1) OR (state = 3);
stall(IN := robust AND moving, PT := t_stall);
IF stall.Q THEN state := 4; valve_extend := FALSE; END_IF;

at_home := (state=0); to_end := (state=1); at_end := (state=2);
to_home := (state=3); error := (state=4);
END_FUNCTION_BLOCK
Result, 1.7 (proper). Reset retracted the cylinder fully home. In Run it extended and retracted continuously. A Stop mid-travel did not halt mid-stroke. The cylinder completed to the limit and halted in Pause (both directions); Start began the next stroke.  PASS, 2/2. Tutor:     Date:

Milestone 1.9  Full station : Main (proper)

The station is four blocks: the environment / main control block (Env), FB_Panel, and the two actuator blocks. Every sensor and valve the actuator FBs must not own lives in Env: the vacuum (Station_2Y1) and ejector-pulse (Station_2Y2) valves, the magazine-empty sensor (Station_B4), the vacuum sensor (Station_2B1), IP_FI, and the Q1 light. In particular Station_2Y1/2Y2 stay out of FB_Actuator_T1, which is what lets that same block drop onto the Testing lift unchanged (milestone L.1). Env also owns the cycle: it issues the four leaving_home/leaving_end move requests and watches the FBs' at_home/at_end outputs, so the station sequence is written purely in the actuator blocks' interface signals.

Figure 12 extends Figure 2 with the Error_state the actuator blocks can force and with reset_done (= both FBs report at_home), which drops the panel back to Pause the moment homing finishes. Start is still ignored in reset_mode, exactly as protocol 1.4 test 6 requires; the reason error recovery is only two presses is that the reset state exits by itself.

Each step is a move request to one actuator block and the transition out of it is that block's arrival output, so Figure 13 composes directly with Figures 4 and 8 — Env never reads a limit switch that belongs to an actuator FB. Steps S1–S7 are the seven steps of protocol 1.9; S8 is the end of batch, where the magazine has emptied, Q1 lights and the arm is stowed at the magazine with the station still in Run, ready to resume if the magazine is refilled. piece_gripped is Station_2B1 after a short vacuum build-up dwell, and the drop uses a matching release-pulse dwell.

PROGRAM Main_Distributing   // the Env block of Figure 11
VAR
    Panel : FB_Panel; Arm : FB_Actuator_T1; Ejector : FB_Actuator_T2;
    si : INT := 0;                 // sequence step, S1..S7 of Figure 13
    t_grip, t_drop : TON;          // vacuum build-up / release-pulse dwells
    go_arm, go_ej, vacuum, eject_pulse, fault, reset_done, mag_empty : BOOL;
    ROBUST : BOOL := FALSE;        // 1.10 = TRUE, 1.9 = FALSE
END_VAR
reset_done := Arm.at_home AND Ejector.at_home;
Panel(s1_start := Panel_S1, s2_stop := NOT Panel_S2,   // panel Stop is wired NC
      s4_reset := Panel_S4, error_in := fault, reset_done := reset_done);
IF Panel.reset_mode OR Panel.error_mode THEN
    si := 0; vacuum := FALSE; eject_pulse := FALSE;
END_IF;
go_arm := FALSE; go_ej := FALSE; eject_pulse := FALSE;
t_grip(IN := (si = 3), PT := T#0.5s);
t_drop(IN := (si = 6), PT := T#0.5s);
// Station_B4 clears as soon as the LAST piece is staged, while that piece still
// has to be transferred, so it only means "empty" at the top of a cycle. Latch it
// there; it self-clears when the magazine is refilled.
mag_empty := Station_B4 AND (mag_empty OR (Panel.run_mode AND si = 0));
IF Panel.run_mode AND NOT mag_empty THEN
    CASE si OF
    0:  IF Arm.at_end  THEN si := 1; ELSE go_arm := TRUE; END_IF;  (* S1 arm downstream *)
    1:  go_ej := TRUE;  IF Ejector.at_end THEN si := 2; END_IF;    (* S2 ejector push   *)
    2:  IF Arm.at_home THEN si := 3; ELSE go_arm := TRUE; END_IF;  (* S3 arm to magazine*)
    3:  vacuum := TRUE; IF t_grip.Q THEN si := 4; END_IF;          (* S4 vacuum grips   *)
    4:  IF Ejector.at_home THEN si := 5; END_IF;                   (* S5 ejector retract*)
    5:  IF Arm.at_end  THEN si := 6; ELSE go_arm := TRUE; END_IF;  (* S6 arm downstream *)
    6:  eject_pulse := TRUE; vacuum := FALSE;                      (* S7 drop, vac off  *)
        IF t_drop.Q THEN si := 0; END_IF;
    END_CASE;
ELSIF Panel.run_mode AND NOT Arm.at_home THEN
    go_arm := TRUE;                    // S8: magazine empty, stow the arm at home
END_IF;
Arm(run_mode := Panel.run_mode, pause_mode := Panel.pause_mode,
    reset_mode := Panel.reset_mode, error_mode := Panel.error_mode,
    sensor_home := Station_3S1, sensor_end := Station_3S2, go := go_arm,
    t_stall := T#2s, robust := ROBUST);
Ejector(run_mode := Panel.run_mode, pause_mode := Panel.pause_mode,
    reset_mode := Panel.reset_mode, error_mode := Panel.error_mode,
    sensor_home := Station_1B1, sensor_end := Station_1B2, go := go_ej,
    t_stall := T#2s, robust := ROBUST);
// An empty magazine is NOT a fault: the latch above ends the batch cleanly.
fault := ROBUST AND ( Arm.error OR Ejector.error
    OR (Panel.run_mode AND vacuum AND si >= 4 AND NOT Station_2B1) );
Station_3Y2 := Arm.valve_to_end;   Station_3Y1 := Arm.valve_to_home;
Station_1Y1 := Ejector.valve_extend;
Station_2Y1 := vacuum      AND NOT Panel.error_mode;
Station_2Y2 := eject_pulse AND NOT Panel.error_mode;
Station_H1  := Panel.start_light;  Station_H2 := Panel.reset_light;
Panel_H3    := mag_empty;          Panel_H4  := Panel.error_mode;   // Q1 / Q2
END_PROGRAM
Result, 1.9 (proper). Reset + 5 workpieces loaded: arm homed, ejector retracted. In Run the 7-step loop ran five times (arm downstream, ejector push, arm upstream, vacuum, ejector retract, arm to end, drop). After the 5th piece the magazine-empty sensor stayed made, so Q1 lit, both actuators returned home, vacuum off, station stayed in Run (step S8 of Figure 13). Pause while the arm moved to delivery froze the arm while the ejector finished its stroke; Start resumed where it left off (both delivery and pickup).  PASS, 3/3. Tutor:     Date:  

Milestone 1.10  Full station : Main (robust)

Same program with ROBUST := TRUE. On top of the two actuators' stall timers, Env raises a fault when the vacuum reports no workpiece once the grip dwell has expired. That single check covers both of protocol 1.10's piece-missing tests: a piece pulled off the suction cup, and the arm arriving at a magazine with no piece staged for it. SCADA : Distributing Station  ·  Milestones S1.1, S1.2

Milestone S1.1  SCADA purpose

The Ignition SCADA interface is a supervisory window onto the Distributing station: on-screen Start / Stop / Reset drive the same FB_Panel state machine as the physical panel; the start / reset / Q1 lamps mirror the panel lights; and an animated schematic shows the live positions of the swivel arm (in-magazine / in-between / in-downstream) and ejecting cylinder (home / in-between / end), with the workpiece moving through the station in real time.

Milestone S1.2  SCADA build

FUNCTION_BLOCK FB_Actuator_T3   // stroke-completing, single retract sensor
VAR_INPUT
    run_mode : BOOL; pause_mode : BOOL; reset_mode : BOOL; error_mode : BOOL;
    sensor_home : BOOL; go : BOOL;
    t_stroke : TIME := T#1s; t_stall : TIME := T#2s; robust : BOOL := FALSE;
END_VAR
VAR_OUTPUT
    at_home : BOOL; to_end : BOOL; at_end : BOOL; to_home : BOOL;
    valve_extend : BOOL; error : BOOL;
END_VAR
VAR state : INT := 0; strokeT : TON; stallT : TON; END_VAR

CASE state OF
0:  IF error_mode THEN state := 4;
    ELSIF reset_mode THEN IF NOT sensor_home THEN state := 3; END_IF;
    ELSIF run_mode AND go THEN state := 1; END_IF;
1:  IF error_mode THEN state := 4; ELSIF strokeT.Q THEN state := 2; END_IF;
2:  IF error_mode THEN state := 4;
    ELSIF reset_mode THEN state := 3;
    ELSIF run_mode THEN state := 3; END_IF;
3:  IF error_mode THEN state := 4; ELSIF sensor_home THEN state := 0; END_IF;
4:  IF reset_mode THEN IF sensor_home THEN state := 0; ELSE state := 3; END_IF; END_IF;
END_CASE;

valve_extend := (state = 1) OR (state = 2);
IF state = 4 THEN valve_extend := FALSE; END_IF;
strokeT(IN := (state = 1), PT := t_stroke);
stallT (IN := robust AND (state = 3), PT := t_stall);
IF stallT.Q THEN state := 4; valve_extend := FALSE; END_IF;

at_home := (state=0); to_end := (state=1); at_end := (state=2);
to_home := (state=3); error := (state=4);
END_FUNCTION_BLOCK
Tuning. Ejector extend measured ~0.5 s; t_stroke set to T#0.7s (just longer than the real travel), t_stall left at T#2s.

Milestone 3.1  Station purpose

The Sorting station is the third and final station: it sorts finished workpieces onto three slides by material and colour. Pieces travel on a conveyor past an inductive metallic sensor and an optical not-black sensor; each piece is classed as metal, red (non-metal, not black) or black.
